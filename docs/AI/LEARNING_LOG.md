# Reusable learning

Add a short entry only when an iteration produces a specific, repeatable lesson that can improve later work. Link the commit or iteration when useful. Do not store credentials, personal data, or speculative conclusions here.

## Lessons

- In Unreal Engine 5.8, run project Python builders with `UnrealEditor-Cmd.exe <project.uproject> -run=pythonscript -script=<script.py>`. Use `LevelEditorSubsystem` for creating, loading and saving maps; `EditorLevelLibrary` emits deprecation warnings.
- A Python builder that regenerates the active map should clear its actors in place. `NewLevel` rejects a map package that already exists, even after an editor asset deletion attempt.
- To move a native UE5 level between projects, preserve the `.umap` and its referenced `.uasset` dependencies under the same `Content` paths, or use Content Browser > Asset Actions > Migrate. The generic Import action is for interchange formats and does not import native `.umap` packages.
- For a playable greybox outpost, model the perimeter as continuous collision geometry and make the wall-top firing path continuous at corners; put stairs on the safe interior side and leave road-facing firing edges open so high cover cannot block aim.
- When an outpost occupies a street junction, stop each approach at the outer wall and attach surrounding building footprints flush to the rear and side walls. Do not add a loop road or traffic path around a fortified position intended to seal the junction; represent the apocalypse with stationary wrecks.
- Keep surrounding building footprints outside the full wall-top walk footprint, including its corners; close the ground-level bypass gaps with corner infill that ends at the walk surface so it does not obstruct the firing route.
- Give the outpost walls and firing walk their own blockout material so the defensive perimeter remains readable against large surrounding building masses in an overhead editor view.
- Size stair runs from the courtyard center to one wall (`compound_half`), not across the entire courtyard; for the 7 m wall walk, 40 treads yield roughly 17.5 cm rise and 37.5 cm depth.
- For axis-aligned perimeter walls, specify their world-space width and depth directly instead of combining rotated actors with component world scaling; verify the rendered side spans from the courtyard view.
- When a wall-top walk is wider than its supporting wall, the overhang can create a sheltered cavity underneath. Fill the complete walk footprint with solid wall down to ground, then end stairs at the wall's inner face.
- When converting the UE first-person template to third person, retain the existing camera getter if gameplay traces depend on it, attach the camera to a spring arm, move relative to controller yaw, orient the body toward travel, and hide the first-person arms while showing the world mesh.
- A playable wave-defense prototype can stay within the Shooter template by deriving its shooter game mode from the native wave game mode and binding defense hotkeys in the existing shooter controller. Keep ammo refill on the weapon API so the existing bullet HUD receives the updated magazine count.
- Unreal `ConstructorHelpers::FClassFinder` must run in an actor constructor, not `BeginPlay`; store the found class during construction and use the stored `TSubclassOf` at runtime. The editor build can succeed even when this runtime-only misuse would crash as soon as PIE spawns the actor.
- When Windows Code Integrity blocks a freshly built Unreal module with policy events 3077/3033, the compile result alone does not mean the editor can load the DLL. Keep the security policy intact and ask the device administrator for an approved signed development build or policy path.
- If the main Unreal project cannot load its native module, a temporary content-only UE project with Python enabled can still import FBX and texture assets. Copy the resulting `.uasset` files back under the same `/Game` content paths so their references remain valid; then validate them in the main project once its module is permitted to load.
- When generating Unreal materials with Python, verify every expression input is connected and set usage flags before applying them to skeletal meshes; a material can be present and saved while Unreal silently falls back to the default material at runtime. Avoid deleting rooted material expressions with `MaterialEditingLibrary.delete_material_expression`; building a clean replacement material is safer.
- For Unreal MCP material edits, update the vector parameter expression's `defaultValue`, then explicitly recompile and save the owning material before judging the in-editor result. A PIE spawn check can confirm lane movement, but zombie proximity alone does not prove outpost damage or keyboard actions; inspect runtime health and spawned defense actors as separate checks.
- For a pawn-free Unreal tower-defense camera, disable `bAutoManageActiveCameraTarget` before unpossessing the starter pawn; otherwise the controller can replace the explicit camera target during play and leave the viewport black.
- In a locked overhead tower-defense view, spend detail on readable silhouettes and color breaks for units, plus graphic features on roof surfaces; facade-only decoration disappears when the camera is high.
- Compose prototype defenses from a dark structural base, a bright upgrade/accent layer, and distinct weapon or utility shapes so turret, bot, and wire remain recognizable at gameplay scale.
- For fixed tower-defense camera stops, use the level's world axes and lane centers to define destinations, animate the camera actor between full transforms, and ignore new stop input until arrival; show the current stop and controls in the HUD.
- When camera stops are connected by drawn radial rails, keep the camera's XY path on each rail and recalculate its rotation toward the outpost throughout the flight.
- Require camera travel to return to the outpost center before changing road spokes; otherwise stop selection permits a diagonal shortcut across the map.
