Morrow District — Unreal Engine 5 level package

This package contains the native LVL_01_MorrowDistrict level for Unreal Engine 5.8, including its three-storey windowed buildings and central fortified outpost.

To add it to another UE5 project:
1. Close the target project in Unreal Editor.
2. Extract this archive at the target project's root so its Content folder merges into the project's Content folder.
3. Reopen the target .uproject and open /Game/Maps/LVL_01_MorrowDistrict in the Content Browser.

The level uses Unreal's BasicShapes cube and cylinder plus the eight included blockout materials. The outpost has a sealed 6.2 m perimeter wall that blocks zombie entry; a player-operated gate is reserved for a later gameplay iteration. The native .umap and .uasset files remain editable. Unreal's generic Import button is for external source formats; for native UE levels, copy the assets with their dependencies or use Content Browser > Asset Actions > Migrate from the source project.
